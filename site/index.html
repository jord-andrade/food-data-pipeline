QUERYABLE EVIDENCE

From raw tables to an answer.

The wide table stays convenient for analysis while the long fact preserves nutrient-level lineage.

SELECT
  description,
  category,
  protein_g,
  energy_kcal,
  fiber_g
FROM food_nutrition_wide
WHERE protein_g IS NOT NULL
ORDER BY protein_g DESC
LIMIT 6;
